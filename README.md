# Programos spartos analizė

Žemiau pateikiami ekrano paveikslėliai, parodantys programos vykdymo laiką skirtingų dydžių duomenų failams:

- Ekrano nuotraukose matyti konsolės išvestis, kurioje nurodyti:
  - Duomenų nuskaitymo laikas
  - Studentų rūšiavimo į vargšius ir kietuosius laikas
  - Išvesties į failus laikas
- Vartotojas gali pasirinkti galutinio balo skaičiavimo metriką (vidurkis ar mediana) ir rūšiavimo tvarką (didėjimo arba mažėjimo).
